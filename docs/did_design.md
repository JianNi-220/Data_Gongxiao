# 大型化肥厂与县级肥料数量：DID 数据准备与识别设计

目前先完成表格数据抽取；尚无工厂清单、开工/投产年份及县域暴露信息，不计算处理变量或因果估计。以下为待合并工厂资料后的实施方案。

## 1. 先明确结果变量

供销志表格中的“销售量”“供应量”“购进量”“调入量”应分别保留，不能直接改名为农户“使用量”。供销系统销售还可能受到库存、跨县销售、其他销售渠道及统计覆盖变化影响；现阶段可研究的是大型工厂对县级供销系统肥料销售/供应数量的影响。只有原表确实报告“施用量”或补充农业统计资料后，才将结果解释为使用量。

保留县名原文、年份、肥料类别、原始品名、业务口径、数量、单位、实物量/折纯量、来源页和核验状态。统一重量单位时保留原值。氮肥、磷肥、钾肥、复合肥按原表分类记录；如仅有尿素、碳铵等品名，则先保留产品层，确认覆盖完整、口径相同且没有“小计＋分项”重复后再汇总。未报告为缺失，不填零；多年合计不拆成年度数；没有养分含量不把实物重量换算成纯氮量。复合肥可能含氮，且也有不含氮的 PK 类型，不能将整个类别预设为不受氮肥供给影响。[FAO 肥料分类资料](https://www.fao.org/4/aq380e/aq380e.pdf)

## 2. 工厂信息和处理时点

工厂表至少需要：厂名、地点/坐标、产品、设计产能及其计量口径、正式开工年、投产年、扩建与停产年份、逐项来源。“大型”应在看结果前用产能门槛定义。研究“新开工”的效果时，以正式开工年份定义事件，允许影响在建设期和投产后逐步出现；研究供给增加时，以投产年份更贴近机制，两种问题应分开报告。

县级首次暴露年份记为 \(G_i\)。暴露规则可以是厂址所在县，或按预先选定的距离/运输联系覆盖的县；需结合销售半径资料确定，并报告替代规则的结果。相邻县如果通过运输网络获得同厂供给，就不能因为没有厂址而直接列为未受处理县。建设公告可能引起提前反应，应记录公告年份并据此设定提前反应窗口。扩产、停产、多个工厂叠加时，简单“首次处理后永久为1”的模型只回答首次暴露问题，不能替代产能强度分析。

## 3. 主分析：县×年 staggered DID

主结果先选口径可比的县级氮肥年度销售/供应数量。使用尚未暴露或样本期始终未暴露县作为比较组，按首次暴露批次估计 \(ATT(g,t)\)，再聚合总体及事件时间效应；报告各批次和事件时间的有效样本。Callaway–Sant’Anna 方法专门处理多期、分批处理及条件平行趋势，可采用组别—时间 ATT 作为主规格。[原论文](https://arxiv.org/abs/1803.09015)

不将普通双向固定效应的单一系数或传统 leads/lags 事件研究直接作为主结果：分批处理且效果异质时，事件时间系数可能混入其他时期的处理效果。可用 Sun–Abraham 事件研究作对应验证。[原论文](https://arxiv.org/abs/1804.05785)

识别需评估：处理前趋势是否可比、厂址与开工时点是否随农业需求变化选择、同期农业/价格/运输政策、县界和统计体系变化，以及跨县供给溢出。绘制处理前动态和置信区间，但“不显著”不等于平行趋势成立。控制变量优先使用处理前特征，避免把受工厂影响的当期变量当作普通控制。标准误的聚类层级应匹配工厂布局及供给冲击层级；共同受同厂影响的多个县不能简单视为独立冲击。

## 4. 其他肥料：比较结果或三重差分

磷肥、钾肥、复合肥可先各自作为结果变量，观察产品间的异质反应；它们不是县级 DID 中的“未处理县”。氮肥价格下降可能导致替代或配套施用，复合肥还可能使用氮肥为原料，因此将它们当作完全不受影响的对照结果需要另行论证。

若产品口径可比，可构造县×年×肥料类别数据，研究“暴露县相对未暴露县，氮肥相对某比较类别的变化”，形成 DDD。它识别的是相对产品效应；只有比较类别的处理效应为零时，才可进一步解释为氮肥的绝对处理效应。关键假设是未受处理时，氮肥与比较类别之间的结果差距在暴露和比较县有可比趋势，不是机械要求每个产品各自都满足同一个 DID 平行趋势。分批处理时还须按批次构造有效比较，不能直接用朴素三重交互项消除异质性问题。[Olden–Møen 原论文](https://doi.org/10.1093/ectj/utac010)

当前最有用的下一步是补齐工厂时点与位置资料，并先检查抽取后的县×年覆盖、业务口径及计量单位；满足这些条件后再确定事件窗口和实际可估计样本。
